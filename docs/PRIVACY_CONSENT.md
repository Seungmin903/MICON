# MICON 개인정보 수집·이용 동의서 (초안 v0.1)

> 상태: **초안**. 회원가입 화면에 표시할 동의 문안과, 동의 항목의 근거를 한 문서에 정리한다.
> 확정 전 반드시 채워야 하는 값은 `[확인 필요]` 로 표시했다. 확정 후 `policy.voice-data.*` 환경 변수(`docs/operations/BACKEND_RUNTIME_CONTRACT.md`)와 앱 내 설정 화면 문구(SET-005)를 이 문서와 일치시킨다.

작성 기준: 「개인정보 보호법」 제15조(수집·이용 동의), 제22조(동의를 받는 방법), 제23조(민감정보) 및 개인정보 보호위원회 「개인정보 처리 방법에 관한 고시」의 필수 고지 4항목 — **수집 항목 · 수집·이용 목적 · 보유·이용 기간 · 거부권과 불이익**.

## 2. [필수] 개인정보 수집·이용 동의 — 계정·서비스 운영

MICON(이하 "서비스")은 회원가입과 서비스 제공을 위해 아래와 같이 개인정보를 수집·이용합니다.

| 수집 항목 | 수집·이용 목적 | 보유·이용 기간 |
|---|---|---|
| 이메일 주소 | 회원 식별, 로그인, 비밀번호 재설정 메일 발송, 중복 가입 확인 | 회원 탈퇴 시까지 |
| 비밀번호 (이메일 가입 시, 암호화하여 저장) | 로그인 인증 | 회원 탈퇴 시까지 |
| Google 계정 이메일 (Google 로그인 시) | 소셜 로그인 인증 및 계정 연결 | 회원 탈퇴 시까지 |
| 기기 식별자, 기기 이름 | 로그인 세션 관리, 기기별 로그아웃, 비정상 접근 탐지 | 로그아웃 또는 세션 만료 시까지 |
| 서비스 이용 기록 (가입일, 최근 로그인 일시, 설정값) | 계정 관리, 서비스 안정 운영 | 회원 탈퇴 시까지 |
| 즐겨찾기 곡, 플레이리스트, 선호 장르·가수 | 개인화 추천 제공 | 회원 탈퇴 또는 삭제 요청 시까지 |
| 연습 기록 (곡, 키, 점수, 일시) | 연습 결과·이력 제공 | 회원 탈퇴 또는 삭제 요청 시까지 |

- 회원 탈퇴 시 위 정보는 지체 없이 삭제합니다. 다만 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다. `[확인 필요: 전자상거래법·통신비밀보호법 등 적용 여부. 유료 결제가 없으면 접속기록(통신비밀보호법, 3개월) 정도만 해당]`
- 탈퇴 후에는 개인을 식별할 수 없는 형태의 기록(녹음 메타데이터의 식별 정보를 제거한 행)만 통계·감사 목적으로 남깁니다.
- 비밀번호는 복구할 수 없는 방식으로 암호화하여 저장하며, 서비스 운영자도 원문을 알 수 없습니다.

**동의를 거부할 권리**: 귀하는 위 개인정보 수집·이용에 동의하지 않을 수 있습니다. 다만 위 항목은 회원가입과 서비스 제공에 꼭 필요한 최소한의 정보이므로, 동의하지 않으면 회원가입이 제한됩니다.

## 3. [필수] 음성 데이터 수집·이용 동의 — 음역·음색 분석

서비스는 귀하의 음역·음색을 분석하고 부를 수 있는 노래와 추천 키를 제공하기 위해 마이크로 녹음한 음성 데이터를 수집·이용합니다.

| 수집 항목 | 수집·이용 목적 | 보유·이용 기간 |
|---|---|---|
| 음성 녹음 (음역 측정·음색 측정·연습 중 녹음) | 음역대·음색 분석, 부를 수 있는 곡과 추천 키 산출, 실시간 음정 피드백 | **분석 완료 후 즉시 삭제** (원본 보관에 별도 동의한 경우 제외) |
| 음성 분석 결과 (최저·최고음, 편안한 음역, 음색 특성, 유사 가수 결과, 음질 판정) | 음역·음색 리포트 제공, 곡 추천, 연습 난이도 산출 | 회원 탈퇴 또는 삭제 요청 시까지 |
| 녹음 메타데이터 (길이, 샘플레이트, 파일 크기, 해시, 녹음 일시) | 분석 품질 검증, 중복 업로드 방지, 삭제 이력 관리 | 회원 탈퇴 시까지 (탈퇴 후 식별 정보 제거) |

- 마이크 권한은 음역 측정·연습을 시작할 때 요청하며, 권한 요청 전에 사용 목적을 화면에서 안내합니다.
- 연습 녹음은 기본적으로 **기기 안에만** 저장되며(앱 데이터 삭제 시 함께 삭제), 서버로 전송되는 것은 음역·음색 분석에 필요한 녹음에 한합니다.
- 서버로 전송된 녹음은 분석 처리를 위해 다음 기간 동안 임시 보관됩니다. `[확인 필요: 현재 코드 기본값은 분석 완료 즉시 삭제 예약, 실패 시 30초 간격 재시도. 정책상 최대 보관 상한(예: 24시간)을 명시할지 결정]`
- 저장된 녹음과 분석 결과는 앱의 **설정 > 음성 데이터 관리**에서 개별 또는 전체 삭제할 수 있으며, 삭제된 데이터는 복구할 수 없습니다.
- 음성 데이터는 개인을 식별·인증하는 생체인식 목적으로 사용하지 않습니다.

**동의를 거부할 권리**: 귀하는 음성 데이터 수집·이용에 동의하지 않을 수 있습니다. 다만 음성 분석은 서비스의 핵심 기능이므로, 동의하지 않으면 회원가입과 서비스 이용이 제한됩니다.

## 4. [선택] 원본 녹음 파일 서버 보관 동의

동의하시면 음역·음색 측정에 사용한 **원본 녹음 파일**을 서버에 보관하여, 나중에 다시 듣거나 재분석에 활용할 수 있습니다.

| 수집 항목 | 이용 목적 | 보유·이용 기간 |
|---|---|---|
| 원본 녹음 파일 (음역·음색 측정) | 녹음 다시 듣기, 분석 결과 재산출, 측정 이력 비교 | 귀하가 삭제하거나 회원 탈퇴할 때까지 `[확인 필요: 최대 보관 기간(예: 1년) 상한을 둘지]` |

- 이 항목의 기본값은 **OFF**입니다. 동의하지 않아도 서비스 이용에 제한이 없으며, 원본은 분석 완료 후 삭제됩니다.
- 언제든지 **설정 > 원본 녹음 저장**에서 끄거나 켤 수 있습니다. 끄면 이후 녹음부터 적용되며, 이미 보관된 녹음은 음성 데이터 관리에서 삭제할 수 있습니다.
- 보관되는 녹음 파일은 암호화된 비공개 저장소(대한민국 서울 리전)에 저장되며, 재생 시에는 짧은 시간만 유효한 주소를 발급해 본인만 접근할 수 있게 합니다.

**동의를 거부할 권리**: 동의하지 않아도 서비스 이용에 불이익이 없습니다.

## 5. [선택] 음성 데이터의 서비스 개선·모델 학습 이용 동의

동의하시면 귀하의 음성 데이터와 분석 결과를 서비스 품질 개선과 음성 분석 모델의 성능 향상에 활용합니다.

| 이용 항목 | 이용 목적 | 보유·이용 기간 |
|---|---|---|
| 음성 녹음, 음성 분석 결과, 연습 결과 | 음역·음색 분석 정확도 개선, 추천 알고리즘 개선, 분석 모델 학습·평가 | 동의 철회 또는 회원 탈퇴 시까지. 단, 이미 학습에 반영된 모델 결과물에서 개별 데이터를 분리해 삭제하는 것은 불가능할 수 있습니다. |

- 학습에 사용할 때는 이메일 등 계정 정보와 분리(가명처리)하여, 데이터만으로는 누구의 목소리인지 알 수 없도록 합니다.
- 언제든지 **설정**에서 동의를 철회할 수 있으며, 철회 이후에는 새로운 학습에 사용하지 않습니다.
- 학습 목적으로 제3자에게 원본 음성을 제공하지 않습니다. `[확인 필요: 외부 사전학습 모델 API 등 제3자 처리 여부. 있으면 6절 위탁·제3자 제공 표에 추가]`

**동의를 거부할 권리**: 동의하지 않아도 서비스 이용에 불이익이 없습니다.

## 8. 앱 화면 적용 (구현됨)

동의 문안과 체크리스트는 `frontend/android/app/src/main/java/com/micon/app/ui/onboarding/PrivacyConsent.kt` 에 있다. 이 문서의 2~5절 문구를 바꾸면 그 파일의 `PrivacyConsentTerms` 도 같이 바꾼다.

### 8.1 회원가입 화면 (`SignupScreen`)

비밀번호 확인 아래에 체크리스트가 들어가고, "보기"를 누르면 전문이 바텀시트로 뜬다.

```
[ ] 전체 동의                                                   (선택 항목까지 켜짐)
[ ] [필수] 서비스 이용약관에 동의합니다                          보기
[ ] [필수] 개인정보 수집·이용에 동의합니다                        보기
[ ] [필수] 음역·음색 분석을 위한 음성 데이터 수집·이용에 동의합니다   보기
[ ] [선택] 원본 녹음 파일을 서버에 보관하는 데 동의합니다            보기
[ ] [선택] 음성 데이터를 서비스 개선·모델 학습에 이용하는 데 동의합니다  보기
```

- 필수 3개가 모두 체크되기 전에는 "회원가입" 버튼이 비활성이다.
- 체크 상태는 화면 회전에만 살아남고 화면을 떠나면 사라진다.
- 마이크 권한은 이 화면에서 요청하지 않는다. 측정 시작 직전에 목적 안내와 함께 요청한다(요구사항 12.2).

### 8.2 비회원 온보딩 (`HoloScreen`)

- 로그인하지 않은 상태로 홀로 분석 화면에 들어오면, **"음역 측정 시작" 또는 "이 곡으로 시작하기"를 처음 누를 때** 동의 다이얼로그가 뜬다. 동의해야 마이크 권한 요청과 측정으로 넘어간다.
- 비회원은 동의를 남길 계정이 없으므로 저장하지 않고, **홀로 화면에 다시 들어올 때마다 다시 묻는다**. 같은 방문 안에서 1단계→2단계로 넘어가거나 다시 측정할 때는 다시 묻지 않는다.
- 비회원에게는 필수 항목(음성 데이터 수집·이용, 비회원용 문안)만 묻고 선택 항목은 묻지 않는다.
- 로그인한 회원은 가입 때 동의했으므로 이 다이얼로그가 뜨지 않는다.

## 9. 남은 작업 (팀 내부용, 문서 확정 후 삭제)

| 항목 | 현재 상태 | 필요한 작업 |
|---|---|---|
| 동의 이력 저장 | 가입 API(`AuthRequest.SignUp`)에 동의 필드·테이블 없음. 앱은 체크만 확인하고 서버에 보내지 않음 | 동의 항목별 `동의 여부·버전·일시`를 저장하는 컬럼/테이블과 가입 요청 필드 추가 (분쟁 시 입증 자료). 이슈로 등록 |
| 선택 동의 → 설정 반영 | 가입 화면의 [선택] 체크 결과가 `user_setting`(원본 저장 여부)에 반영되지 않음. 학습 동의 값은 설정 자체가 없음 | 가입 직후 원본 저장 설정 API 호출, 학습 동의 설정 항목·API 추가 및 설정 화면에서 철회 가능하게 |
| Google 가입 경로 | 로그인 화면의 "구글로 시작하기"가 토큰 검증 후 바로 계정을 만들어 동의 화면을 거치지 않음 | 서버가 신규 가입 여부를 응답하면 최초 1회 동의 화면 경유하도록 분기 |
| 기존 회원 | 이 기능 이전에 가입한 회원은 동의 이력이 없음 | 동의 이력 저장이 들어가면 다음 로그인 때 1회 동의 화면 표시 |
| 정책 문구 API | `policy.voice-data.*` 기본값이 `UNCONFIRMED`, `정책 확정 전` | 본 문서 확정 후 운영 환경 변수에 실제 값 기입 |
| 탈퇴 시 삭제 | `UserDataCleanupService`가 추천·음성·연습·즐겨찾기·설정 삭제, 녹음 행은 식별정보 제거 | 2절 "탈퇴 후 남기는 기록" 설명과 일치함. 법정 보존 항목 확정 시 반영 |
