# timbre_v2 — 음색 분리(disentanglement) 실험

시작: 2026-08-29. 1차(timbre_eval/)는 팀 발표용으로 동결 — 인수인계는 timbre_eval/HANDOFF.md,
팀 문서는 timbre_eval/timbre_explainer.html (아티팩트 동일본).

## 목표

1차의 정직한 고백에서 출발: 현 구조는 분리가 아니라 "얽힌 임베딩을 평균으로 갈라 쓰는 근사"다.
v2는 음색 정체성(B)과 민감도(Δ, 조건부 음색)를 실제로 따로 읽는 것을 목표로 한다.

사다리 (싼 것부터):
1. **f0 잔차 제거** (exp01) — 트랙 내부 변동에서 피치 방향을 회귀 추정해 제거.
   주의: 전역 회귀는 성별(정체성)까지 지우므로 반드시 트랙 중심화 후 잔차에서만 추정.
2. 조건별 프로토타입 — 조각을 f0×RMS 밴드로 층화한 조건별 centroid (1차 메타 재사용)
3. 창법 통제 녹음 — 같은 소절 3창법 (1차 청취세션 파트2와 공유), Δ 검증의 유일한 재료
4. 표현 수준 분리 학습 (SVC 계열 / 2-head contrastive) — 학습 인프라 필요, 최후순위

## 데이터·캐시 (1차 재사용, 복사 금지)

- 조각 임베딩: `../timbre_eval/emb_cache_v2/ecapa/<트랙>.npy` (L2 정규화, 조각순)
- 조각 메타: 같은 폴더 `.meta.json` — chunks[i]가 npy i행과 동일 표집 (build_meta 보장)
- 게이트: `../timbre_eval/asnorm.py`의 load_pool() (그룹·듀엣·라이브 제외)
- 벤치마크 눈금 (1차 기준값): 커버 gap +0.127 / AUC 0.902 / selfID 36/46 /
  피치 얽힘 ρ≈-0.95 / 같은사람 저↔고밴드 0.816

## 실험 로그

### exp01 f0 잔차 제거 (2026-08-29) — 방향 유효, 크기 제한적 (강한 시사)

트랙 중심화 회귀(조각 3,135개)로 피치 방향 제거. 코어 134 동결세트, 전/후:

| 지표 | 원본 | 제거 후 | 읽기 |
|---|---|---|---|
| 트랙내 cos↔\|Δst\| ρ | -0.537 | -0.434 | 얽힘 ~19% 감소 — 선형 성분만 제거됨, 비선형 잔존 |
| 커버 gap / AUC | +0.127 / 0.902 | +0.128 / 0.904 | 정체성 무손실 (오차 내) |
| selfID | 36/46 | 37/46 | 동등~미세 개선 |
| 저↔고밴드 같은사람/타인 | 0.786/0.484 | 0.839/0.519 | 교차음역 자기유사도 개선, 격차도 소폭 확대 |

주의: 이 표의 ρ와 밴드 수치는 exp01 자체 정의(1차의 ρ≈-0.95, 0.816과 지표 정의가 달라 직접 비교 금지 — 열 안에서 전/후만 비교).
결론: 공짜 개선(정체성 비용 0)이므로 채택 후보. 단 얽힘의 대부분은 비선형이라 이것만으로 "분리" 주장 불가 → 다음 단은 조건별 프로토타입(층화가 비선형을 우회).

### exp02 조건별 프로토타입 (2026-08-29) — 기각(잠정)

f0 밴드(저/고) 층화 프로토타입 vs 통짜 centroid, leave-one-track-out 가수 재발견(질의 331트랙, 후보 386명):
top-1 84.3%(통짜) vs 81.9%(층화), top-5 90.3% vs 90.9%, 짝지은 부호검정 p=0.37 — 차이 없음~통짜 우세.
해석: ①밴드 분할로 프로토타입당 조각 반감 → 추정 노이즈가 조건 이득 상쇄 ②이건 정체성 과제 기준이라
Δ의 본래 용도(조건부 사용자↔곡 매칭)는 미검증 — 그 판정은 창법 통제 녹음 확보 후(사다리 3단).
재개 조건: 가수당 조각 수가 늘거나(카탈로그 곡 증가), 통제 녹음으로 조건 매칭을 직접 검증할 때.

### exp03 f0 잔차 × 밀도 스트레스 (2026-08-29) — 규모에서 무효과 (중립)

풀 614트랙(조각 14,332개로 재추정) 본인 재발견: top-1 74.3%→74.3%, 개선 28/악화 28 (p=1.0).
트랙 통짜 비교에서는 밴드 효과가 평균에 상쇄 — exp01의 교차음역 개선은 카탈로그 검색에는 안 나타남.
결론: 카탈로그 쪽 무해 확인. 채택 판정은 사용자 축(창법·음역 다른 녹음 매칭) 검증으로 이월.

### exp04 IRCAM 가수 인코더 맞대결 (2026-08-29) — ECAPA 승, 모델 선정 종결 (확정적)

노래 전용 자기지도 인코더(SonyCSL/IRCAM, ISMIR 2023) byol·contrastive를 코어 134 하니스에 투입:
AUC ECAPA 0.902 vs contrastive 0.824 vs byol 0.726, selfID 36/46 vs 14~15/46 — 완패.
(절대 gap은 IRCAM이 커 보이나 스케일 함정 — 순위 지표로 판정.) 패인 후보(전부 가설):
Demucs 잔류물 도메인 불일치, 레퍼토리 차이, 피치 불변 학습의 정보 손실, 5M 소형 백본.
모델 선정 누적 전적: 음악 모델(MERT·MuQ·FACodec) → 최신 화자 모델(WavLM-SV) → 노래 전용(IRCAM×2)
모두 ECAPA에 패배. **정체성 축 인코더는 ECAPA로 확정, 남은 개선 방향은 인코더 교체가 아니라
전처리(20초 창)·정규화(z-norm)·사용자 축 검증.**
