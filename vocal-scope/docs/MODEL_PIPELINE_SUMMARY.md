# VocalScope 모델 파이프라인 요약

> **구식 문서(2026-08-27 기준, HTDemucs 시절).** 현재 파이프라인은 Mel-Band RoFormer 분리·성구 판정·가창 채점·키 조절을 포함합니다. 최신 정리는 루트 `PIPELINE.md`, 산출 데이터 전수 목록은 `docs/DATA_INVENTORY.md`를 보세요.

## 1. 음원 전처리 및 보컬 분리

VocalScope는 원곡을 분석하기 쉬운 WAV 형식으로 변환한 후, HTDemucs를 이용하여 보컬과 반주를 분리합니다.

HTDemucs는 여러 악기와 목소리가 섞인 음원에서 원하는 소리를 분리하는 딥러닝 음원 분리 모델입니다. 보컬만 별도로 추출함으로써 드럼이나 베이스와 같은 반주가 보컬 음정으로 잘못 인식되는 문제를 줄입니다.

## 2. 음정과 박자 분석

분리된 보컬의 음높이는 CREPE full 모델이 분석합니다. CREPE는 음성의 기본 주파수, 즉 가수가 부른 음의 높이를 짧은 시간 단위로 추정하는 딥러닝 피치 분석 모델입니다.

VAD는 음량과 CREPE의 분석 결과를 활용하여 실제로 노래하는 구간을 찾습니다. Viterbi 알고리즘은 여러 음정 후보 가운데 시간의 흐름에 따라 가장 자연스럽게 연결되는 음정을 선택합니다.

이후 pYIN이 다른 신호처리 방식으로 음정을 다시 분석하여 CREPE의 결과를 검증하고 옥타브 오류를 보정합니다. 동시에 librosa는 원곡의 리듬을 분석하여 BPM, 첫 박과 박자표를 추정합니다.

## 3. 음표 생성 및 가사 정렬

확정된 음정 곡선은 음높이의 변화와 음절의 시작점을 기준으로 개별 음표로 나뉩니다. 각 음표를 박자 격자에 맞춰 정렬하고 조성을 분석하면 원곡의 멜로디를 표현하는 MIDI와 MusicXML 악보가 생성됩니다.

가사가 입력되지 않은 경우에는 Whisper turbo를 사용합니다. Whisper turbo는 음성을 텍스트로 변환하는 다국어 음성 인식 모델로, 분리된 보컬을 분석하여 한국어 가사를 받아씁니다.

이후 wav2vec2 한국어 CTC 모델이 가사 정렬을 담당합니다. 이 모델은 음성과 문자 사이의 시간 관계를 분석하여 각 가사 음절이 실제 노래에서 언제 시작되고 끝나는지를 계산합니다.

## 4. 노래방용 악보 완성

마지막으로 음정 분석을 통해 만든 음표와 wav2vec2가 계산한 가사 음절의 타이밍을 결합합니다.

이 과정에서 지나치게 짧은 장식음이나 불필요한 음표를 정리하고, 음표의 시작점을 일정한 박자 격자에 맞춥니다.

그 결과 원곡의 특징을 유지하면서도 사용자가 쉽게 따라 부를 수 있는 기준 멜로디가 만들어집니다. 최종적으로 한글 가사와 음이름이 포함된 노래방용 MIDI 및 MusicXML 악보가 출력됩니다.

## 5. 사용 모델 및 기술

| 구분 | 모델·기술 | 역할 | 입력 | 출력 |
|---|---|---|---|---|
| 딥러닝 | HTDemucs | 원곡에서 보컬과 반주를 분리하는 음원 분리 모델입니다. | 원곡 음원 | 보컬 음원, 반주 음원 |
| 딥러닝 | CREPE full | 보컬의 기본 주파수를 분석하여 시간별 음높이를 추정하는 피치 분석 모델입니다. | 분리된 보컬 | 피치 확률, 음정 후보 |
| 규칙 기반 | VAD | 음량과 피치 신뢰도를 바탕으로 실제 가창 구간을 판별합니다. | 보컬 음원, CREPE 결과 | 가창 구간 |
| 알고리즘 | Viterbi | 여러 음정 후보 중 시간상 가장 자연스럽게 연결되는 음정을 선택합니다. | CREPE 피치 확률 | 연속적인 음정 곡선 |
| 신호처리 | pYIN | CREPE의 음정 결과를 교차 검증하고 옥타브 오류를 보정합니다. | 분리된 보컬 | 보정된 음정, 신뢰도 |
| 알고리즘 | librosa 박자 분석 | 원곡의 리듬을 분석하여 BPM, 첫 박과 박자표를 추정합니다. | 원곡 음원 | BPM, 박 위치, 박자표 |
| 알고리즘 | 음표 분절 및 격자 정렬 | 음정 곡선을 개별 음표로 나누고 박자에 맞게 정렬합니다. | 음정 곡선, 박자 정보 | 원곡 채보 음표 |
| 알고리즘 | Krumhansl–Schmuckler | 음표 분포를 분석하여 곡의 장조·단조와 조성을 추정합니다. | 채보된 음표 | 조성, 조표 |
| 딥러닝 | Whisper turbo | 가사가 없을 때 보컬 음성을 인식하여 가사 텍스트를 생성합니다. | 분리된 보컬 | 한국어 가사 |
| 딥러닝 | wav2vec2 한국어 CTC | 가사의 각 음절을 실제 보컬의 시작·종료 시점에 맞춰 정렬합니다. | 보컬 음원, 가사 | 음절별 시간 정보 |
| 규칙 기반 | 노래방 멜로디 생성 | 음표와 가사를 결합하고 장식음을 정리하여 부르기 쉬운 멜로디로 변환합니다. | 음표, 음절 타이밍 | 노래방용 악보 |
| 출력 변환 | pretty_midi·music21 | 분석 결과를 MIDI와 MusicXML 악보 파일로 변환합니다. | 최종 음표, 가사 | MIDI, MusicXML |

## 6. 전체 처리 흐름

`원곡 입력 → HTDemucs 보컬 분리 → CREPE 음정 분석 → VAD·Viterbi·pYIN 음정 보정 → librosa 박자 분석 → 음표 생성 → Whisper 가사 인식 → wav2vec2 음절 정렬 → 노래방용 MIDI·MusicXML 생성`
