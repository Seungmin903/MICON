# 음색 매칭 실험 인수인계 (0단계 완료 시점)

작성: 2026-08-28. 이 문서 하나로 다음 세션이 전체 맥락을 복원할 수 있어야 한다.
사용자: 지유림 — 근거 없는 수치·서사를 즉시 적발함. 메모리 규칙 2개 준수: ①사후 스토리텔링 금지(CI 없이 수치 차이 해석 금지, 확정/강한시사/가설 등급 표기) ②근거 없는 낙관 금지(시간 추정은 관측 속도로 산수).

## 1. 프로젝트

노래 추천 서비스: 사용자의 목소리로 ①부를 수 있고(음역) ②목소리에 어울리는(음색) 곡 추천. 요구사항 명세서에 음성 분석 리포트(음역 지도·안정성·육각형)·노래 추천·연습 기능. 이 폴더(timbre_eval/)는 **음색 축의 모델 선정·검증 실험 일체**. 음역 축은 f0(RMVPE/pyin) 별도 파이프라인 예정.

핵심 개념 합의:
- **음색 정체성(B)** = 곡·환경·음높이를 벗겨낸 불변량 — 매칭의 뼈대. **조건부 음색(Δ)** = 음높이·성구·강도에 따른 변화 — 메타데이터로 기록, 매칭 반영은 v2. 기술 문서에서 맨몸의 "음색" 단어 사용 금지(팀 용어집과의 충돌 원인이었음).
- 추천 구조(합의): 음역 필터 → 음색 점수(0.6×z(트랙) + 0.4×z(가수 centroid), **신호별 z정규화 후 혼합** — raw 혼합은 sd(가수)≈2×sd(트랙)이라 실효 43:57로 뒤집혔었음, 2026-08-28 교정) → 취향/재정렬. MERT는 음색 탈락 후 곡 분위기(곡↔곡 비교) 담당으로 배치. 가중치는 로그 학습 전까지 휴리스틱.
- 평가 철학: 음색 추천의 절대 정답은 없음 → 상대 비교(모델 간)·행동 지표(출시 후)·최소 청취 확인만 필수.

## 2. 파이프라인 (최종 사양 v2)

mp3/m4a → 44.1kHz wav(실패 시 imageio-ffmpeg 폴백) → Demucs htdemucs 보컬 분리(풀해상도에서) → 모노 → 트랙별 문턱(상위10% RMS×0.15) → 5초 비중첩 창, 유성프레임>60%만 합격 → **곡 전체 균등 표집 ≤24개 + 조각별 RMS 정규화(0.1)** → 16kHz 리샘플 → ECAPA-TDNN(speechbrain) → 조각당 192차원, L2 정규화 → 캐시 `emb_cache_v2/ecapa/<트랙>.npy` + `.meta.json`(조각별 f0·원시RMS·유성비율·응집도 / 트랙별 SNR프록시·클리핑·저신뢰·듀엣 플래그).
- 유사도 = 두 트랙 전 조각쌍 코사인의 평균 (트랙평균벡터 코사인과 스케일 다름 — 혼용 금지, 과거 한 번 사고남)
- v1(구버전: 앞 24조각, 정규화 없음) 캐시는 `emb_cache/` — 참고용. 본 수치 대부분 v1로 계산됐고 v2로 결론 불변 확인됨.

## 3. 데이터 (data/, 총 845트랙 처리됨 — 2026-08-29 TJ ~770곡 증설, pipeline_800.py)

증설 후 플래그: 듀엣(이름) 109, 저신뢰 198(23% — 팝·아이돌 프로덕션 탓, 기존 10%의 2배). 게이트 최종 수치(다곡가수 self-ID, 앨리어스 병합): 기존 게이트 풀 614에서 top-1 74.3%/top-5 87.9%, 저신뢰 제외(풀 537) top-1 78.8%/top-5 91.2%. **무표기 피처링(Justin Bieber 'Baby')은 이름+응집도 이중 게이트를 모두 통과 — 이 유형은 현 게이트로 못 잡음(한계 확정)**. 로테이션 그룹은 groups.txt(수동)로 제외. 시각화: vector_map.py(인터랙티브 지도), meta_sheet.py(플래그 시트).

### 구 데이터 구성 (134트랙 시절)

- 밤편지 커버 7인(아이유·웬디·설윤·경서 여 / 첸·존박·규현 남) — 콘텐츠 불변성 십자검증의 핵심
- 아이유 밤편지 4버전(스튜디오/라이브2/콘서트) — 환경 분해용. **라이브·콘서트는 실험 재료일 뿐, 추천 풀에서 제외(게이트)**
- 제이플라·솔라 커버 각 3곡(같은 채널=같은 녹음체인) — 스타일 몫 측정
- 이영현 3곡 — 다른 계열 여성 변별 대조
- TJ 카탈로그 ~91곡(가수__TJ코드_official__제목 규칙) — 갤러리 밀도·규범 분포용
- 폰 녹음: 지유림 4건(밤편지 집/노래방, 체념, 1,2,3,4 — 창법·환경 자체 통제 세트), 정다운 1건(노래방 MR 포함)
- 이하이 3곡(Rose·짝사랑·안전지대) — 지유림의 "닮았다고 듣는 가수" 예측 검증용. 구원자는 B.I 피처링 오염으로 삭제됨

## 4. 실험과 결과 (전부 timbre_eval/*.py 로 재현 가능)

| 실험 (스크립트) | 결과 |
|---|---|
| 커버 십자검증 (evaluate/analyze) | ECAPA 승: 간격+0.127, EER 0.287, 같은곡-다른가수를 목소리 기준으로 분리. MERT 간격+0.014, MuQ +0.007(30초 입력 재실험도 악화 muq30.py), FACodec +0.007(가창에서 붕괴), singer_id는 아래 사유로 탈락 |
| 환경 분해 (env_analysis) | ECAPA: 환경비용<곡비용, 순서 유지. singer_id: 환경이 정체성 압도(자기 라이브보다 타인이 가까움) → 탈락 확정 |
| 피치 교란 (pitch_check, pitch_shift_test) | ECAPA 교차음역 유사도는 피치와 ρ≈-0.95 상관, +3st 조작에 9/9 순위 밀림 — 피치 얽힘은 측정된 한계. 동성/동음역 비교는 순수 목소리 차이 |
| 스타일 몫 (b_analysis) | 같은체인 곡간: 제이플라 0.469(≈환경쌍 0.466, 스타일몫≈0) vs 솔라 0.305(카멜레온) — 스타일 몫은 사람 의존 0~0.16, 정체성 격차(~0.18)가 대체로 우위 |
| 음역 밴드 (band_test) | 같은사람 저↔고밴드 0.816 ≫ 타인 0.546 → "음역별 음색" 실재하나 사람차이의 절반 이하. 고밴드끼리 타인 유사도 0.589>저밴드 0.504 → 고음역 식별력 저하(강한 시사) |
| 30초 입력 (thirty_sec_test, self_id, pseudo_user) | 30초 창의 최근접=자기자신, 사람 단위 28/28. 128트랙 확장 시 120/128(실패는 본인 타곡·듀엣·박빙 닮은꼴 — 정상 밀도 현상). 안재욱 '친구' 90-120s 창은 코러스 구간(사람 청취로 확인) → 극단 구간 30초의 위험 |
| 발성 강도 (dynamics_test) | 여리게↔세게 0.691>타인 0.551, 단 하위10%는 타인 이하로 붕괴. 강도-음높이 교란 +6.4st 미분리 — 순수 창법 축은 통제 녹음 필요(미실행) |
| 사용자 통제 세트 (juyurim_analysis, reverb_check) | 노래방 녹음은 잔향 편향(+0.03, 라이브 음원 쪽으로) + 절대값 인플레. **계열 판정(아이유·경서 여성 소프트)은 4녹음 전부 불변**. 집 녹음이 전 지표 최상 → 온보딩 "조용한 곳 무반주" = 품질 사양 |
| 곡측 잔향 가설 (reverb_bias_test) | 기각(잠정): wetness↔순위 ρ≈±0.11 무상관. 단 프록시가 무딤(제이플라가 양극단에 동시 등장=편곡 꼬리 오염) |
| LDA 백엔드 파일럿 (lda_pilot) | 13명 학습→분리 채점: EER 0.366→0.417 악화. 소표본 과적합 — 다곡가수 ~100명 시점에 재실행 |
| 이하이 예측 (demo_rec) | 지유림 집 녹음에서 이하이 Rose 3위(0.434)·안전지대 5위 — 사용자 귀와 모델 정렬(1호 지각 검증). 단 예측자=채점자 편향 유의 |
| 동종 최신모델 맞대결 (wavlm_bench, 2026-08-29) | WavLM-SV(base-plus)가 가창에서 붕괴: AUC 0.712 vs ECAPA 0.902, selfID 7/46 vs 36/46 — 검토 11번(화자인식 계열 내부 비교) 1차 종결, ECAPA 유지 확정. 주의: WavLM 계열 중 base-plus 변형 1개와의 비교 |
| 민감도 스윕 (sweep_sensitivity, 2026-08-28) | 코어 134트랙 동결세트. **20초 창이 5초보다 우세**: AUC 0.902→0.930, selfID 짝변화 7↑/1↓(맥니마 p≈0.07, 강한 시사). 24→48조각 무효과, RMS 목표 무영향, 문턱·유성 ±2배 강건, 집계 중앙값 근소 우세. 20초 전환 보류 조건: ①사용자 30초=조각1개 문제 ②게이트 해상도 하락 미측정 ③기존 수치 재검 필요 — 사용자 매칭 결정실험 후 판단 |
| 밀도 스트레스 (845트랙 임베딩, 2026-08-28) | 게이트 후 619~728트랙 풀에서 솔로 다곡가수 top-1 self-ID 70.8%(기존 98%은 134트랙 기준), **top-5 86.3%, 본인곡 순위 중앙값 1등**. 하락 원인은 지문 오염 아님(실패군 응집도 0.691 vs 성공군 0.707 — 실질 동일, 저신뢰 게이트로 회복 불가 확인). 원인=닮은꼴 밀도+라벨 앨리어싱(나얼=브라운아이즈 등). **로테이션 그룹(아이돌)은 self-ID 14%로 붕괴 → groups.txt 게이트 신설**(load_pool에 파일명 듀엣 폴백도 추가) |
| 점수 정규화 (asnorm) | 권장=전체코호트 z-norm(랭킹 보존, 노래방 인플레 정의상 제거). top-K z-norm은 과교정(-0.610 sd [CI -0.773,-0.446], raw +1.339), 표준 AS-norm(u+t)은 절반 교정+랭킹 교란(ρ0.63)이라 보류. 한계: 환경의 순위 상호작용은 정규화로 못 고침(z집↔z노래방 ρ0.696) → 온보딩 품질 사양이 정답. 측정은 집↔노래방 쌍 1개 — 강한 시사 |

가수 섬 지도: 성별 대륙이 비지도로 형성, 정승환↔성시경 상호 최근접(유명 닮은꼴), 다곡가수 트랙 43개 중 42개가 최근접=본인(98%, 예외=솔라 Golden→에일리). **2D 지도 이웃보존율 27% — 쌍별 결론은 반드시 원공간(neighbors.md)으로**.

## 5. 품질 게이트 (구현됨)

- 듀엣 플래그: 파일명 파싱(쉼표·&·Feat) — 7건. bimodality(2군집) 탐지기는 검증 실패(알려진 듀엣 0/3)로 철회, 판정 사용 금지 표기
- 저신뢰 플래그: 응집도<0.40 또는 이상조각≥4 — 13건 (듀엣·카멜레온·환경혼합 포착)
- 추천 풀 제외: 듀엣 + 환경 변형판(아이유 라이브·콘서트). **아이유는 이후 실험에서 스튜디오만 사용(사용자 지시)**
- 이름 게이트 구멍 확인됨: 이하이 '구원자'(B.I 피처링, 파일명 무표기) 통과. **이중화로도 못 잡는 유형 확정(2026-08-29)**: Justin Bieber 'Baby'(짧은 무표기 랩 피처링)가 이름·응집도 둘 다 통과(응집도 0.477, 이상조각 0) — 짧은 피처링은 24조각 표집에 안 걸림(가설). 완전 해결은 외부 크레딧 DB, v1은 감수
- 그룹 게이트 원칙(2026-08-29): 이름 일괄 배제가 아니라 **"지문이 재현 가능한 목소리 실체인가"로 판정** — 애매한 팀은 곡간 자기유사도+최근접=본인그룹 검사. 사례: 빅마마(0.432, 2/2 — 실은 멤버 솔로 트랙, 라벨이 거짓·소리가 진실)·브라운아이즈(→나얼)는 풀 유지, SG워너비(0/4)·다비치(0/3)·거북이·쿨은 제외 정당. 악뮤는 측정상 4/4이나 혼성 로테이션 사전지식으로 제외 유지(사용자 결정). 로테이션 그룹 명단 groups.txt(수동)

## 6. 솔직한 평가

**강점**: 모든 결론이 통제 실험+상대 비교 기반. 적대적 재검증으로 자체 오류 5건 적발·수정(스케일 혼용, 표집 편향, 음량 미정규화, 역전 지표 결함, 데이터 시점 혼재). 전처리 민감도(v2) 재실험으로 결론 불변 확인. 반론이 오면 반나절 내 측정으로 전환되는 하니스 보유.

**약점(인용 시 주의)**: ①표본 소규모 — 개별 소수값 신뢰구간 없음, 방향·순위만 결론 근거(score_ci.py로 CI 확인 가능) ②EER 절대값 인용 금지(청크 상관으로 과대 표본) ③피치·강도·창법 교란 미완전 분리 ④지각 검증(사람 귀) 미실행 — **유일하게 남은 관문 = 청취 세션**(청취세션_프로토콜.md: 2AFC 8문항 + 창법 3종 녹음 + 자유 청취) ⑤원곡 스템의 화음·더블링 잔류 영향 미확인 ⑥웬디 신곡 출처(라이브 의심) 미확인 ⑦ECAPA 가중치 VoxCeleb 학습 — 상용 라이선스 검토 필요.

**기각/보류된 아이디어**(재논쟁 방지): MERT/MuQ를 음색에(프로빙≠검색 — 라벨 학습 붙이면 별개), 사용자 목소리를 MERT에 넣는 0.5/0.5 앙상블(콘텐츠 오염), bimodality 듀엣 탐지, 잔향 강건성 파인튜닝(게이트 정책으로 충분), 현 규모 LDA 백엔드, 곡측 잔향 대응.
