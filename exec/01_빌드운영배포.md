# MICON 빌드·운영·배포 안내

기준일: 2026-09-28 · 팀 코드: B110 · 서비스명: MICON

## 구성과 버전

| 구성 | 제품/기술 | 저장소 기준 버전·설정 |
|---|---|---|
| Android 앱 | Kotlin, Jetpack Compose, Android Gradle Plugin | JDK 21, Gradle Wrapper 9.5.0, AGP 9.3.2, Kotlin 2.2.10, compileSdk 37 / targetSdk 36 / minSdk 24 |
| 백엔드 API | Java, Spring Boot, 내장 Tomcat | Java 21, Spring Boot 4.1.1, Gradle Wrapper 9.7.1, 기본 컨테이너 포트 8080 |
| 관계형 DB | MySQL | 컨테이너 이미지 MySQL 8.4.11, DB 이름 `micon`; Flyway 마이그레이션 사용 |
| 추천·음성분석 AI | Python, FastAPI/Uvicorn, PyTorch | Dockerfile Python 3.11-slim, PyTorch 2.7.1 CPU; 기본 포트 8788, Uvicorn worker 1 |
| 웹 프록시 | Nginx | 외부 HTTPS 및 `/api/v1/` 경로를 백엔드로 프록시. 실제 서버 패키지 버전은 런타임 서버에서 별도 확인 필요 |
| 파일 저장소 | AWS S3 | 서울 리전 `ap-northeast-2`, 비공개 버킷. 앱은 S3 자격 증명을 갖지 않고 백엔드 발급 URL 사용 |

버전은 `origin/develop`의 Gradle wrapper, Android 버전 카탈로그, Dockerfile, Compose, 운영 문서를 기준으로 적었습니다. 외부 SSAFY/Jenkins 서버에 설치된 Nginx·Docker·JDK의 실제 버전/빌드 번호는 서버 점검으로 확인해야 하며 여기서 추정하지 않습니다.

## 소스 및 빌드

모노레포 주요 경로:

- `frontend/android/`: Android 앱
- `backend/`: Spring Boot API 및 Flyway 마이그레이션
- `ai/recommend-server/`: 추천·음성분석 FastAPI 서버
- `infra/compose/`, `infra/deploy/`: 컨테이너·배포 설정
- `docs/operations/`: 환경·운영 원본 문서

Android 개발 빌드(저장소 루트에서):

```powershell
cd frontend\android
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

백엔드 빌드/테스트:

```powershell
cd backend
.\gradlew.bat test
```

AI 서버는 `ai/recommend-server/Dockerfile`을 빌드해 별도 컨테이너로 운영합니다. 모델 가중치는 이미지 빌드 때 설정 절차에서 받아 SHA-256을 검증합니다. 앱은 AI 서버에 직접 연결하지 않고 백엔드 API를 사용합니다.

## 설정 파일과 환경변수

실제 비밀값은 Git에 기록하지 않습니다. 아래 파일은 이름과 사용 목적을 확인하는 기준이며 실제 값을 채운 운영 파일은 저장소 밖에서 관리합니다.

| 위치 | 역할 |
|---|---|
| `frontend/android/local.properties` | 개인 Android SDK 위치와 개발용 `API_BASE_URL`, `ENGINE_BASE_URL` BuildConfig 값. 개인 PC 전용 |
| `backend/.env.example` | 백엔드 환경변수 이름 목록. Spring Boot는 `.env`를 자동 읽지 않으므로 Compose/실행기가 주입 |
| `infra/compose/backend.env.example` | 비밀이 아닌 Compose 기본값 예시 |
| `infra/compose/recommendation.env.example` | AI 추천 서버의 비밀 아닌 런타임 설정 예시 |
| `infra/compose/*.yml` | 앱·DB·AI 컨테이너, 네트워크, 볼륨 및 secret 파일 경로 |
| `docs/operations/BACKEND_RUNTIME_CONTRACT.md` | 환경변수별 형식·필수 여부·기본값·보안 주의점 |
| `docs/operations/ANDROID_RELEASE.md` | Android Release 서명·버전·산출물 절차 |

주요 백엔드 환경변수는 다음과 같습니다. 비밀 값은 이 문서에 기재하지 않습니다.

- DB/인증: `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `JWT_SECRET`, `GOOGLE_WEB_CLIENT_ID`, `GOOGLE_JWK_SET_URI`
- 메일: `MAIL_FROM`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_SMTP_AUTH`, `MAIL_STARTTLS`
- AI 연결: `AI_SERVICE_TOKEN`, `AI_VOICE_ANALYSIS_*`, `AI_RECOMMENDATION_*`, `AI_SONG_FIT_ENABLED`
- S3 및 미디어: `VOICE_STORAGE_*`, `CATALOG_MEDIA_*`, `SONG_PREVIEW_*`, `AWS_SHARED_CREDENTIALS_FILE`, `AWS_PROFILE`, `AWS_EC2_METADATA_DISABLED`
- Spotify 이미지 조회: `SPOTIFY_IMAGE_ENABLED`, `SPOTIFY_ACCOUNTS_BASE_URL`, `SPOTIFY_API_BASE_URL`, `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_MARKET`
- 앱 로컬 빌드: `sdk.dir`, `API_BASE_URL`, `ENGINE_BASE_URL`

운영에서 `.env`, AWS 자격증명, OAuth/Spotify 비밀값, JWT 및 DB 비밀번호를 출력하거나 저장소·APK에 넣지 않습니다. CI 로그에는 값이 아닌 성공/실패와 빌드 SHA만 남깁니다.

## DB 계정과 연결 속성

운영 설계는 `micon` 데이터베이스에 관리자, 마이그레이션, 런타임 계정을 분리합니다.

| 계정 역할 | 사용 범위 |
|---|---|
| DBA/root | 인프라 관리 전용. 애플리케이션에서 사용하지 않음 |
| `micon_migrator` | Flyway 스키마 마이그레이션 수행 |
| `micon_app` | 서비스 런타임의 최소 권한(조회·추가·수정·삭제) |

연결 속성은 `DB_URL`(JDBC MySQL URL), `DB_USERNAME`, `DB_PASSWORD`로 주입합니다. 실제 자격증명 파일은 서버의 제한된 secret 경로(`/etc/micon/secrets/`)에서 관리하며 공유 문서에는 값·서버 비밀번호를 적지 않습니다. DB 포트는 외부에 공개하지 않고 내부 컨테이너 네트워크로 연결합니다.

## 배포 흐름과 주의사항

1. 작업 브랜치에서 테스트 후 MR을 만들어 develop에 리뷰·병합합니다. `main`·`develop` 직접 push는 저장소 규칙상 금지입니다.
2. 배포할 커밋 SHA와 CI 결과를 확인한 뒤 Jenkins에서 빌드/배포 상태를 확인합니다. Jenkins job의 현재 활성화 상태는 job 실행 이력으로 확인해야 합니다.
3. BE 배포는 DB 호환성·Flyway 적용 순서와 백업을 확인한 뒤 수행합니다. DB migration이 포함된 버전이면 BE를 먼저 배포하고 상태를 검증한 후 앱을 배포합니다.
4. AI 추천 서버는 백엔드와 별도 컨테이너/서비스로 관리합니다. 코드만 Git에 있는 것과 AI 운영 서버 배포 완료는 같은 뜻이 아닙니다.
5. Nginx 라우팅은 `/api/v1/` 외부 경로를 내부 API에 전달합니다. readiness, 주요 API, S3 GET 검증 없이 트래픽 전환 성공으로 판단하지 않습니다.

운영 상태·절차 원문: `docs/operations/DEPLOYMENT_READINESS.md`, `SERVER_BOOTSTRAP.md`, `SERVER_RELEASE_RUNBOOK.md`, `JENKINS_BACKEND_CD.md`, `JENKINS_ANDROID_CI.md`, `NGINX_BACKEND_ROUTING.md`, `MYSQL_RUNTIME.md`, `S3_VOICE_STORAGE.md`. 문서상의 과거 검증 결과를 현재 Jenkins 성공/운영 배포 완료로 확대 해석하지 않습니다.
