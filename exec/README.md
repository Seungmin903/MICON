## 확인이 남은 제출 항목

- 최신 DB 자료: [schema-only V1~V39](MICON_SCHEMA_ONLY_V1_V39.sql)를 만들었습니다. 최신 develop commit `596be2f24441f79210fce24a975cbd64e0394512`의 migration을 숫자 순서로 합치고 모든 DML을 제외했으므로 사용자 데이터와 reference seed 데이터가 없습니다. 새 빈 MySQL 8.4.11 스키마용이며 운영 DB에 실행하면 안 됩니다. Docker 엔진이 이 PC에서 실행되지 않아 실제 MySQL 적용 검증은 못 했습니다.
- 게시 전 최종 확인: GitLab `exec/` 변경은 `docs/PLAN/submissionPackage` 브랜치에 push했고, `develop` 대상 MR !338이 열려 있습니다. EduSSAFY 영상 포트폴리오 게시글은 제목·AI 기술 설명까지 입력했지만, 브라우저 자동화에서 파일 선택 창을 제어할 수 없어 영상·발표 PDF 첨부와 게시가 남았습니다. GitLab 프로젝트 표시명은 `MICON`으로 바꿨습니다.
- 작업 저장소 상태: 공유 작업 폴더의 기존 클론은 feature 브랜치이며 `origin/develop`보다 45커밋 뒤에 있고, Android 파일 7개에 기존 미커밋 변경이 있습니다. 이 변경을 건드리거나 포함하지 않도록 문서 업로드는 최신 develop 기반의 별도 worktree에서 준비했습니다.
