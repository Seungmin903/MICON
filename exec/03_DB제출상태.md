# DB 덤프·스키마 제출 상태

기준일: 2026-09-28 · 팀 코드: B110 · 서비스명: MICON

## 현재 확인된 자료

- 프로젝트의 최신 스키마 변경 원본은 `backend/src/main/resources/db/migration/`의 Flyway migration V1~V39입니다.
- [MICON_SCHEMA_ONLY_V1_V39.sql](MICON_SCHEMA_ONLY_V1_V39.sql)은 이 migration 39개를 숫자 버전 순서로 합쳐 만든 빈 DB용 schema-only 스냅샷입니다. `INSERT`/`UPDATE`/`DELETE`/`REPLACE` 문을 제외해 사용자 행과 reference seed 데이터를 포함하지 않습니다.
- `docs/MICON_COMPLETE_DDL.sql`은 파일 이력과 주석상 2026-09-11 및 Flyway V1~V7 시점의 참고 DDL입니다. 현재 전체 스키마 덤프로 제출하면 안 됩니다.
- 로컬 Downloads의 `MICON.sql`은 2026-09-07 파일이며, 테이블 생성문은 있으나 데이터 INSERT는 없습니다. 저장소의 MySQL 운영 문서도 기존 공유 DDL의 구조 오류 및 Flyway와의 충돌을 지적하므로 최신본으로 제출하지 않습니다.
- 운영 DB에서 직접 `mysqldump`한 파일은 아닙니다. Docker Engine이 현재 로컬 PC에서 실행되지 않아 빈 MySQL 8.4.11에 migration을 적용하는 실행 검증도 아직 수행하지 않았습니다. 파일은 소스 migration 기반의 구조 스냅샷입니다.

## 안전한 제출 방식

이번 제출은 요청에 따라 데이터 없는 **schema-only** 자료를 사용합니다. 실제 운영 데이터 export가 추가로 요구되면 DB 담당자가 승인한 절차로 별도 생성하고, 사용자 식별자·토큰·연습 기록 등은 제외/비식별화합니다. 운영 자격증명은 공유하지 않습니다.

운영 DB에 임의로 접속·dump/import하거나, 오래된 `MICON.sql`/`MICON_COMPLETE_DDL.sql`을 최신으로 표기해 제출하지 않습니다. 스키마 파일은 빈 DB 생성 검증 후 제출하는 것을 권장합니다.
