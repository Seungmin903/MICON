# MICON 외부 서비스 연동 정보

기준일: 2026-09-28 · 팀 코드: B110 · 서비스명: MICON

실제 키·토큰·비밀번호는 외부 공개 문서에 기록하지 않습니다. 권한이 필요한 값은 저장소 밖의 secret 파일이나 보호된 CI/CD 변수로 관리합니다.

| 서비스 | 사용 목적·연동 흐름 | 필요한 설정(값은 별도 보관) | 운영 주의사항 |
|---|---|---|---|
| Google OAuth 2.0 | 앱의 Google 로그인 토큰을 백엔드에서 검증 | Web client ID, 공개 JWK 주소; `GOOGLE_WEB_CLIENT_ID`, 선택 `GOOGLE_JWK_SET_URI` | Client secret/개인 키는 앱·Git에 넣지 않음. 허용 패키지/SHA 지문과 웹 클라이언트 설정을 함께 확인 |
| Spotify Web API | 카탈로그의 앨범 이미지 조회·캐시 | `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, API base URL, 시장 코드 및 조회 기능 플래그 | 요청 수·캐시 TTL을 지키고 이미지 출처/표시 정책 확인. Client Secret은 서버에서만 사용 |
| AWS S3 | 원곡 미리듣기·반주·카탈로그 자산 및 설정에 따른 음성 녹음 보관 | 비공개 버킷, 리전, prefix; BE 전용 AWS profile/credential 파일 | 앱에 AWS key를 포함하지 않음. 카탈로그와 사용자 녹음 prefix·권한 분리. 장기 공개 URL 대신 백엔드 발급 단기 URL 사용 |
| MICON AI FastAPI | 음성 분석·음색 임베딩·추천 및 곡 적합도 | 내부 HTTPS/컨테이너 URL, `AI_SERVICE_TOKEN`, AI 계약·모델 버전 | 앱이 직접 호출하지 않고 BE가 중계. AI server는 별도 배포이므로 GitLab 코드 반영만으로 운영 업데이트되지 않음 |
| SMTP 제공자 | 비밀번호 재설정 메일 | `MAIL_FROM`, `MAIL_HOST`, `MAIL_PORT`, 선택 계정/비밀번호, auth/TLS 정책 | 제공자 인증·TLS 및 발송 성공을 확인하기 전 비밀번호 재설정 기능의 운영 정상화를 주장하지 않음 |
| GitLab / Jenkins | 소스 형상관리·MR 검토·테스트·빌드/배포 자동화 | 저장소 프로젝트와 보호된 Runner/Jenkins credentials | job 활성화·배포 성공은 해당 파이프라인의 최근 실행으로 별도 확인. secret 원문을 MR/로그에 기록하지 않음 |

연동 설정 원본: `backend/.env.example`, `docs/operations/BACKEND_RUNTIME_CONTRACT.md`, `S3_VOICE_STORAGE.md`, `RECOMMENDATION_CONTAINER_RUNTIME.md`, `ANDROID_RELEASE.md`.
