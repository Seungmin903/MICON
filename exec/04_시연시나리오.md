# MICON 시연 시나리오

기준일: 2026-09-28 · 팀 코드: B110 · 서비스명: MICON

## 시연 전 준비

- 시연용 Android 기기와 앱 버전, 로그인 가능한 테스트 계정, 네트워크를 사전 확인합니다.
- 테스트 계정에 음역 프로필·선호 설정을 미리 준비하고, 추천 API/곡 카탈로그/S3 미디어 접근을 점검합니다.
- 실사용자 계정·비밀번호·음성 녹음이 노출되지 않도록 테스트 계정을 사용합니다. 마이크 권한과 오디오 볼륨을 미리 확인합니다.

## 시연 순서

| 단계 | 화면·조작 | 설명/보여줄 결과 |
|---|---|---|
| 1. 로그인·음성 프로필 | MICON 실행 후 테스트 계정 로그인. 신규 프로필 시 온보딩 음역 측정 진행 | 사용자의 음역·발성 특성을 분석해 프로필을 만드는 진입점 |
| 2. 추천 | 추천 화면에서 곡 목록 열기 | 보컬 임베딩 유사도와 음역 적합도를 바탕으로 사용자에게 맞는 곡을 제시 |
| 3. 곡 상세·키 가이드 | 곡 하나 선택, 적합도와 권장 키 확인 | 곡의 음역과 사용자 안정 음역을 비교하고 몇 키 올리거나 내릴지 안내 |
| 4. 연습·키 조절 | 연습 진입, 반주 재생 후 화면의 키 조절을 한두 번 누르고 음정 피드백 표시 | S3의 키별 반주 자산과 실시간 피치 추적을 이용해 음높이를 조절하고 연습 피드백 제공 |
| 5. 기록·분석 | 연습 종료 후 결과/연습 기록 화면 열기 | 세션별 점수·음정 결과를 확인해 이전 연습을 돌아볼 수 있음 |

## 설명할 기술 포인트

- 음역 측정·추천에는 서버의 AI 분석/추천 파이프라인과 앱의 화면·연습 흐름이 함께 동작합니다.
- 앱에서 실시간으로 음정을 읽는 YIN 추적은 신호처리이며, 서버의 대형 AI 모델과 구분해서 설명합니다.
- 키 이동은 원곡 재생 속도를 바꾸는 방식이 아니라 준비된 키별 반주 자산을 사용합니다.
- 데모 중 실제 사용자 녹음·개인정보를 공개하지 않고, 사전에 검증한 테스트 계정을 사용합니다.
