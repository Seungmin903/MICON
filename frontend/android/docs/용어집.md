# 1. 사용 원칙

## 1.1 용어 수준

- **물리량**: 주파수, 음압, 진폭처럼 단위와 측정 방법이 있는 값
- **신호 피처**: RMS, spectral centroid, HNR처럼 신호에서 계산한 관측값
- **모델 표현**: 임베딩, 프로토타입처럼 모델이 학습하거나 집계한 표현
- **지각 표현**: 밝다, 두껍다, 거칠다처럼 사람이 느낀 특성을 요약한 말
- **제품 지표**: 음역 적합도, 음색 관계 점수, 종합 적합도처럼 여러 근거를 결합한 서비스용 값

피처는 음색의 정답이 아니라 음색을 서로 다른 관점에서 관측한 값이다. 제품 지표에는 사용한 입력, 계산 방식, 모델 버전과 신뢰도를 함께 관리한다.

## 1.2 권장 명칭

- 사용자 화면에서는 익숙한 표현인 **음역대**를 사용할 수 있다.
- 데이터와 기술 문서에서는 **음역**을 기본 명칭으로 사용한다.
- **톤**, **볼륨**, **음정**, **키**, **유사도**는 단독으로 쓰지 않고 구체적인 의미를 붙인다.
- 예: 음색, 녹음 라우드니스, 피치 정확도, 곡 원키, 키 시프트, 음색 임베딩 유사도

# 2. 프로젝트 핵심 오디오 용어

- **음원**: 분석 또는 재생에 사용하는 모든 오디오 데이터. 원곡, 사용자 녹음, 보컬 stem, 반주를 포함한다.
- **원곡 또는 완성 믹스**: 보컬과 모든 악기 및 후처리가 합쳐진 발매 버전.
- **보컬**: 노래 또는 랩을 수행한 사람의 음성 신호.
- **리드 보컬**: 곡의 주선율과 주요 가사를 담당하는 보컬.
- **백킹 보컬 또는 코러스**: 리드 보컬을 보조하는 화음, 더블링, 코러스.
- **stem**: 완성 믹스에서 분리했거나 제작 단계에서 개별로 제공된 소리 묶음. 완벽한 생목 또는 개별 악기라고 보장하지 않는다.
- **보컬 stem**: 보컬 중심으로 분리한 오디오. 반주 누출과 분리 아티팩트가 포함될 수 있다.
- **반주 또는 accompaniment**: 사용자가 노래할 수 있도록 리드 보컬이 제거된 재생용 오디오.
- **MR**: 일상 용어로는 반주 음원을 뜻하지만 의미가 일정하지 않다. 내부 데이터명은 accompaniment 또는 instrumental stem을 사용한다.
- **무반주 가창**: 스피커 반주가 마이크에 들어가지 않도록 사용자의 목소리만 녹음한 입력. 이어폰으로 가이드를 듣는 경우도 포함할 수 있다.
- **구간 또는 section**: verse, chorus, bridge, peak, rap처럼 별도로 분석하는 곡의 일부.
- **프레임**: 오디오를 수십 ms 단위의 짧은 창으로 나눈 분석 단위.
- **세그먼트**: 여러 프레임으로 구성된 의미 있는 유효 보컬 구간.

# 3. 소리 신호 기초 용어

- **파형 waveform**: 시간에 따른 마이크 신호의 변화.
- **진폭 amplitude**: 파형의 순간적인 크기. 디지털 진폭은 실제 성량과 동일하지 않다.
- **주파수 frequency**: 1초 동안 반복되는 진동 횟수. 단위는 Hz.
- **위상 phase**: 주기적인 신호가 한 주기 안에서 놓인 위치.
- **샘플 sample**: 특정 시점의 디지털 신호값.
- **샘플링 레이트 sample rate**: 1초에 기록하는 샘플 수. 예: 44.1 kHz는 초당 44,100개.
- **비트 깊이 bit depth**: 샘플 진폭을 표현하는 정밀도.
- **PCM**: 파형을 시간순 숫자로 저장하는 대표적인 디지털 오디오 표현.
- **시간 영역**: 파형, 음의 시작과 끝, RMS와 강약 변화를 시간축에서 보는 관점.
- **주파수 영역**: 한 구간에 어떤 주파수 성분이 얼마나 있는지 보는 관점.
- **FFT**: 짧은 신호 구간을 주파수 성분으로 변환하는 계산.
- **STFT**: 시간에 따라 FFT를 반복하여 주파수 성분의 변화를 보는 방법.
- **스펙트럼**: 특정 구간의 주파수별 에너지 분포.
- **스펙트로그램**: 시간, 주파수, 에너지를 함께 나타낸 표현.

# 4. 음높이 용어

- **기본주파수 F0**: 성대 진동의 기본 반복 주파수. 보컬 피치 추정의 주요 대상.
- **피치 pitch**: 사람이 지각하는 소리의 높낮이. 시스템에서는 주로 F0로 근사한다.
- **주파수와 피치의 차이**: 주파수는 물리적인 진동 성분이고 피치는 지각되는 높낮이다. 하나의 목소리에는 F0와 다수의 배음 주파수가 함께 존재한다.
- **음표 또는 음높이 note**: C4, A4처럼 음악 체계에 맞춰 표현한 높이.
- **MIDI note**: 음높이를 반음 단위의 숫자로 표현한 값. A4는 일반적으로 69.
- **센트 cent**: 반음의 1/100. 미세한 피치 차이에 사용한다.
- **옥타브 octave**: 주파수가 두 배 또는 절반이 되는 간격.
- **음정 간격 interval**: 두 음높이 사이의 음악적 거리.
- **피치 정확도**: 목표 음높이와 사용자가 낸 음높이가 얼마나 가까운지 나타내는 값.
- **피치 안정성**: 한 음을 유지하는 동안 F0가 목표 주변에서 얼마나 안정적으로 유지되는지 나타내는 값.
- **피치 추적 pitch tracking**: 시간에 따른 F0를 연속적으로 추정하는 과정.
- **유성 voiced**: 주기적인 성대 진동이 있어 F0를 추정할 수 있는 상태.
- **무성 unvoiced**: 마찰음, 파열음, 숨소리처럼 명확한 F0가 없는 상태.
- **유성 비율 voiced ratio**: 분석 구간 중 유성으로 판정된 시간의 비율.
- **옥타브 오류**: F0를 실제 값의 두 배 또는 절반으로 잘못 추정한 현상.
- **곡의 원키 original key**: 발매 버전 또는 기준 반주의 조성·기준 높이.
- **키 시프트 key shift**: 곡 전체를 반음 단위로 높이거나 낮추는 조정값.
- **조옮김 transposition**: 음정 관계를 유지하면서 곡 전체의 높이를 이동하는 것.
- **추천 키 selected key**: 사용자의 편안 음역과 곡 구간을 비교해 제안한 키 시프트.
- **상대 음높이 위치**: 해당 음이 사용자의 실사용 또는 편안 음역 안에서 어느 위치에 있는지를 0~1 또는 센트 거리로 표현한 값.

# 5. 음역 용어

- **발성 가능 음역**: 사용자가 한 번이라도 낼 수 있는 관측 최저음부터 최고음. 곡 전체를 안정적으로 부를 수 있다는 뜻은 아니다.
- **실사용 음역 practical range**: 실제 가창에서 최소 품질과 지속 조건을 만족하며 사용할 수 있는 음역.
- **편안 음역 comfortable range**: 무리 없이 반복적으로 부를 수 있고 피치·음색·지속력이 비교적 안정적인 음역.
- **안정 음역 stable range**: 사전에 정한 안정도 기준을 통과한 음높이의 연속 구간. 편안 음역의 기술적 근사치로 사용할 수 있다.
- **성구별 음역**: 진성 우세, 믹스, 두성 우세, 가성 우세 등 발성 상태별로 관측된 음역.
- **최저음과 최고음**: 분석 조건에서 관측된 양 끝의 음. 단일 순간값보다 최소 지속 시간과 신뢰도 조건을 함께 사용한다.
- **테시투라 tessitura**: 곡에서 음들이 주로 머무는 중심 음역. 단순 최고음보다 체감 부담과 관련성이 높다.
- **구간별 음역**: verse, chorus, peak 등 각 곡 구간의 음역 분포.
- **음역 폭**: 최저음과 최고음 사이의 반음 수.
- **지속 고음**: 높은 음을 일정 시간 이상 유지해야 하는 구간.
- **고음 지속력**: 사용자가 기준 이상의 높은 음을 안정적으로 유지할 수 있는 시간과 품질.
- **부담 구간**: 곡의 목표 음높이가 사용자 편안·안정 음역을 벗어나거나 지속·성구 전환 부담이 큰 구간.
- **음역 적합도**: 후보 키에서 곡의 테시투라와 구간별 음역이 사용자 편안·실사용 음역에 얼마나 들어오는지를 나타내는 제품 지표.
- **음역 궤적**: 시간에 따른 곡 또는 사용자 가창의 음높이 변화.
- **음역대**: 사용자 친화적 표현으로 사용할 수 있으나 내부 기술 명칭은 음역을 사용한다.

# 6. 음량과 마이크 용어

<aside>
🎙️

마이크는 실제 성량을 직접 측정하지 않는다. 마이크 위치에 도달한 음압을 전압과 디지털 진폭으로 변환한다. 기기, 거리, 방향, 게인과 AGC가 통제되지 않았다면 녹음값은 절대 성량으로 표현하지 않는다.

</aside>

- **음압 sound pressure**: 마이크 위치에서의 공기 압력 변화. 단위는 Pa.
- **음압 레벨 dB SPL**: 기준 음압 20 μPa와 비교한 물리적인 소리 크기. 보정된 마이크 또는 음압계가 필요하다.
- **녹음 레벨**: 디지털 파일에 기록된 신호 크기.
- **dBFS**: 디지털 최대값을 0 dB로 둔 녹음 레벨 단위. 0 dBFS에 가까울수록 클리핑 위험이 크다.
- **Peak**: 분석 구간에서 가장 큰 순간 진폭.
- **RMS**: 분석 구간의 평균적인 신호 에너지를 나타내는 값.
- **Short-time RMS**: 짧은 창마다 RMS를 계산하여 시간에 따른 강약을 표현한 값.
- **엔벌로프 envelope**: 시간에 따른 신호 크기의 외곽 변화. 어택, 유지, 감쇠 분석에 사용한다.
- **라우드니스 loudness**: 사람이 지각하는 소리 크기.
- **LUFS**: 청각 특성을 반영한 음원 라우드니스 단위. 보정되지 않은 생목의 실제 성량 단위가 아니다.
- **볼륨 volume**: 재생 장치 설정 또는 일상적인 크기 표현으로 의미가 모호하다. 기술 문서에서는 녹음 레벨, 라우드니스 또는 음압으로 구체화한다.
- **성량**: 가수가 공간에 목소리를 전달하는 능력을 포함한 가창 개념. 보정되지 않은 스마트폰 진폭만으로 절대값을 산출하지 않는다.
- **발성 강도**: 동일 사용자·거리·기기 조건에서 약하게 또는 강하게 발성한 상대적인 상태.
- **다이내믹스**: 한 프레이즈 또는 곡 안에서 사용하는 강약의 변화.
- **다이내믹 레인지**: 작은 구간과 큰 구간의 레벨 차이.
- **게인 gain**: 마이크 또는 프리앰프가 입력 신호를 증폭하는 정도.
- **AGC**: 기기가 작은 소리를 키우고 큰 소리를 줄이는 자동 게인 조절.
- **마이크 감도**: 같은 음압에 대해 마이크가 출력하는 전기 신호의 크기.
- **마이크 거리**: 입과 마이크 사이의 거리. 동일 발성에서도 거리가 멀어지면 입력 레벨이 낮아진다.
- **마이크 방향성**: 방향에 따라 소리를 받아들이는 정도가 달라지는 특성.
- **클리핑**: 신호가 표현 가능한 최대 범위를 넘어 파형이 잘리는 현상.
- **클리핑 비율**: 전체 샘플 중 클리핑으로 판정한 샘플의 비율.

# 7. 진성·가성 및 필수 가창 용어

## 7.1 발성 상태와 성구

- **발성 phonation**: 성대 진동과 성도 공명을 이용해 소리를 만드는 방식.
- **성구 register**: 음높이와 발성 방식에 따라 음질 및 성대 작동이 달라지는 영역 또는 상태.
- **진성 또는 modal voice**: 성대 접촉과 주기성이 비교적 분명하고 말소리와 연결된 밀도 있는 발성. 흉성과 완전히 같은 말로 고정하지 않는다.
- **흉성 chest voice**: 주로 저·중음에서 말소리와 유사한 밀도와 감각을 보이는 성구 개념.
- **두성 head voice**: 높은 음역에서 성대 조절과 공명 전략이 달라지는 연결된 발성. 가성과 동일하지 않다.
- **가성 falsetto**: 성대 접촉이 상대적으로 약하고 공기성 음질이 두드러지는 발성.
- **믹스 보이스 mixed voice**: 흉성·두성 특성을 조절하여 중고음과 고음을 연결하는 발성 전략.
- **성구 전환 register transition**: 발성 상태가 바뀌면서 음색과 진동 방식이 변화하는 과정.
- **전환 구간 passaggio**: 성구 조절이 크게 필요한 음높이 구간.
- **보이스 브레이크**: 성구 전환 과정에서 피치나 음색이 갑자기 끊기거나 뒤집히는 현상.
- **성구 판정 신뢰도**: 모델이 진성·가성 등의 발성 상태를 얼마나 안정적으로 구분했는지 나타내는 값.

프로젝트에서는 확정적 이진 라벨보다 진성 우세, 가성 우세, 혼합 또는 불명확과 같은 상태 및 신뢰도를 권장한다. 같은 음높이에서도 진성·믹스·가성 프로토타입이 각각 존재할 수 있다.

## 7.2 꼭 필요한 가창 표현

- **어택 또는 onset**: 음을 시작하는 방식과 시작 순간의 특성.
- **서스테인 sustain**: 한 음을 일정 시간 유지하는 구간 및 능력.
- **비브라토 vibrato**: 유지음에서 피치와 크기가 주기적으로 변화하는 표현.
- **프레이징 phrasing**: 가사와 선율을 음악적인 단위로 끊고 연결하는 방식.
- **딕션 diction**: 가사의 발음과 전달 방식.
- **호흡 프레이즈**: 한 번의 호흡으로 처리하는 가창 구간.
- **리듬 정확도**: 목표 박자와 실제 발성 시점의 일치 정도.

# 8. 음색 용어와 공식 정의

## 8.1 음색의 공식 정의

> **음색 timbre**: 비슷한 음높이, 크기와 발음 조건에서도 서로 다른 목소리로 지각하게 만드는 스펙트럼 및 시간적 특성의 집합.
> 

본 프로젝트는 음색을 언어 라벨로 직접 정의하지 않는다. 스펙트럼, 배음, 공명, 주기성과 시간적 변화에 관한 복수의 음향 피처, 학습된 임베딩과 측정 조건의 조합으로 표현한다. 언어 표현은 사용자 설명을 위한 보조 수단으로만 사용한다.

## 8.2 관측된 보컬 음색의 네 층

- **고유 음색 또는 음색 정체성**: 곡과 발성이 달라도 비교적 유지되는 개인의 음성 특징.
- **발성 질감**: 숨소리성, 거칠기, 압착성처럼 같은 사람도 의도와 상태에 따라 바꿀 수 있는 음질.
- **가창 표현**: 비브라토, 프레이징, 어택, 성구 전환처럼 시간에 따라 변하는 표현. 음색과 관련되지만 별도 축으로 저장한다.
- **녹음 음색**: 마이크, 방, EQ, 압축, 리버브, 오토튠, 더블링과 분리 아티팩트가 만든 결과. 고유 음색으로 간주하지 않고 품질·도메인 정보로 관리한다.

## 8.3 음높이 조건부 음색

- **음높이 조건부 음색 pitch-conditioned timbre**: 특정 절대 음높이, 개인 음역 내 상대 위치, 성구와 발성 강도에서 관측되는 음색.
- **기준 음색 base timbre**: 음높이와 발성 조건이 달라도 비교적 유지되는 사용자 특성의 모델 표현.
- **조건부 음색 변화 timbre delta**: 특정 음높이·성구·발성 강도에서 기준 음색으로부터 달라지는 부분.
- **음색 궤적 timbre trajectory**: 음높이와 발성 상태가 변할 때 음색 피처와 임베딩이 연속적으로 변화하는 경로.
- **개인 음역 내 상대 위치**: 같은 절대 음이라도 사용자에게 저음·중음·고음 중 어디에 해당하는지 나타내는 조건값.
- **조건부 비교**: 비슷한 음높이·성구·발성 강도·발음 조건의 구간끼리 음색을 비교하는 방식.

개념식은 다음과 같다.

$$
T_u(p,r,d,v)=B_u+\Delta_u(p,r,d,v)
$$

여기서 u는 사용자, p는 음높이, r은 성구, d는 발성 강도, v는 모음 또는 발음 조건, B는 기준 음색이다.

## 8.4 음색을 관측하는 피처

### 스펙트럼 구조

- **스펙트럼 포락선 spectral envelope**: 주파수별 에너지 분포의 전체적인 외곽 형태.
- **스펙트럼 중심 spectral centroid**: 스펙트럼 에너지의 무게중심. 밝기와 관련될 수 있으나 음높이·모음·마이크 영향도 받는다.
- **스펙트럼 기울기 spectral slope**: 낮은 주파수에서 높은 주파수로 갈수록 에너지가 감소하는 정도.
- **스펙트럼 롤오프 spectral roll-off**: 누적 에너지의 일정 비율이 포함되는 주파수 경계.
- **스펙트럼 평탄도 spectral flatness**: 배음성 신호와 잡음성 신호를 구분하는 보조 지표.
- **MFCC**: 스펙트럼 포락선을 청각 척도에서 압축해 나타낸 피처 묶음.

### 배음과 성대 진동

- **배음 harmonics**: F0의 정수배에 해당하는 주파수 성분.
- **배음 구조**: 배음별 에너지와 감소 양상으로 이루어진 분포.
- **주기성 periodicity**: 신호가 일정한 주기로 반복되는 정도.
- **HNR**: 배음 성분과 잡음 성분의 비율.
- **CPP**: 음성의 주기성과 성대 진동의 선명도를 나타내는 피처.
- **H1-H2 계열**: 첫 번째와 두 번째 배음의 관계를 이용해 발성 질감을 관찰하는 피처. 모음과 음높이 조건을 함께 봐야 한다.

### 공명

- **포먼트 formant**: 성도 공명으로 강조되는 주파수 대역.
- **포먼트 대역폭**: 각 포먼트가 차지하는 주파수 폭.
- **안티포먼트 anti-formant**: 비강 결합 등으로 특정 주파수 성분이 약해지는 공명 특성.
- **공명 구조**: 포먼트, 안티포먼트와 스펙트럼 포락선이 함께 만드는 성도 특성.

### 시간 변화

- **어택 시간**: 음이 시작되어 목표 에너지에 도달하는 데 걸리는 시간.
- **스펙트럼 플럭스 spectral flux**: 연속 프레임 사이에서 스펙트럼이 얼마나 변하는지 나타내는 값.
- **구간 내 변동성**: 한 구간에서 음색 피처가 얼마나 안정적이거나 변화하는지 나타내는 통계.
- **음색 변화율**: 시간 또는 음높이 변화에 따른 음색 표현의 변화 정도.

## 8.5 학습된 음색 표현

- **음색 임베딩 timbre embedding**: 모델이 보컬의 복합적인 특징을 고차원 벡터로 표현한 값.
- **가창자 정체성 임베딩**: 곡과 구간이 달라도 동일 가창자의 안정적인 특징을 찾도록 학습한 표현.
- **임베딩 유사도**: 두 임베딩 사이의 거리 또는 코사인 유사도. 곡 적합도나 확률과 동일하지 않다.
- **프로토타입 prototype**: 여러 유효 구간을 대표하는 피처 또는 임베딩.
- **다중 프로토타입 multi-prototype**: 저·중·고음, 진성·가성, 약·강 발성 등 조건별로 여러 대표 표현을 보관하는 방식.
- **구간 프로토타입**: verse, chorus, peak 등 곡 구간별 대표 음색 표현.
- **피처 분포**: 평균 하나가 아니라 중앙값, 표준편차, 분위수와 시간 변화를 함께 저장한 표현.
- **이웃 안정성**: 반복 녹음, 기기와 방이 달라져도 가까운 음색 이웃의 순위가 유지되는 정도.

## 8.6 지각적 음색 표현

다음 표현은 모델의 정답 라벨이 아니라 설명 및 검수용 연속 축이다.

- **밝음 ↔ 어두움**: 고주파 배음과 스펙트럼 분포 등에 관련된 지각적 특성.
- **얇음 ↔ 두꺼움**: 저·중역 에너지, 배음 및 공명 구조가 만드는 밀도감.
- **맑음 ↔ 숨소리성**: 명확한 주기성과 공기성·소음성 성분의 상대적인 인상.
- **부드러움 ↔ 거칠기**: 매끄러운 주기성부터 불규칙하고 소음성인 질감까지의 인상.
- **구강성 ↔ 비성**: 구강 공명과 비강 공명의 상대적인 인상.
- **이완됨 ↔ 압착성**: 부드럽게 흐르는 발성부터 눌리거나 단단하게 접촉하는 듯한 인상.

지각 축은 서로 독립적이지 않으며 음높이, 모음, 발성 강도, 마이크와 후처리의 영향을 받는다. 특정 축을 사용자의 고정 성격이나 취향으로 해석하지 않는다.

## 8.7 음색 관련 제품 지표

- **음색 유사도**: 통제된 조건에서 두 보컬 표현이 얼마나 가까운지를 나타내는 모델 값.
- **음색 관계 점수**: 사용자 음색과 곡의 보컬 요구가 가까움, 조화 또는 대비 중 어떤 관계를 이루는지 나타내는 제품 지표.
- **음색 적합도**: 음역·성구·구간 조건을 고려해 사용자의 음색 궤적과 곡의 구간별 보컬 요구가 얼마나 맞는지 나타내는 추천 지표.
- **음색 신뢰도**: 유효 세그먼트 수, 녹음 품질, 조건 일치와 반복 안정성을 반영한 신뢰 수준.
- **원곡처럼 붙는 관계**: 사용자와 원곡 보컬의 음색·표현이 가까운 추천 관계.
- **새롭게 해석하는 관계**: 음역과 곡 분위기는 맞지만 원곡 보컬과 음색이 적당히 달라 사용자의 특성이 드러날 수 있는 추천 관계.

음색 유사도는 곡 적합도와 동일하지 않다. 음색 차이는 항상 감점 대상이 아니다.

# 9. 분석 품질 용어

- **분석 품질**: 입력 오디오와 중간 산출물이 목표 피처를 신뢰할 수 있게 계산할 조건을 만족하는 정도.
- **배경 잡음**: 목표 보컬 이외의 환경음.
- **노이즈 플로어**: 유효 보컬이 없을 때 관측되는 기본 잡음 수준.
- **SNR**: 목표 음성 신호와 잡음의 에너지 비율.
- **잔향 reverb**: 직접음 이후 공간 반사음이 이어지는 현상.
- **잔향 시간 RT60**: 소리 에너지가 60 dB 감소하는 데 걸리는 시간. 짧은 사용자 녹음에서는 추정 신뢰도를 함께 관리한다.
- **바람 잡음**: 공기 흐름이 마이크 진동판에 직접 작용해 생기는 강한 저주파 잡음.
- **파열음 plosive**: ㅂ, ㅍ 등의 발음에서 공기가 마이크에 직접 닿아 생기는 순간적인 저주파 충격.
- **반주 누출**: 이어폰 또는 스피커의 반주가 사용자 녹음에 함께 들어오는 현상.
- **stem 누출 leakage**: 분리된 보컬에 반주가 남거나 반주에 보컬이 남는 현상.
- **분리 아티팩트**: 보컬 분리 과정에서 생기는 금속성 소리, 떨림, 구멍 난 스펙트럼 등의 왜곡.
- **오토튠 플래그**: 강한 피치 보정 가능성이 있어 원가수의 자연 발성을 직접 비교하기 어렵다는 표시.
- **더블링 플래그**: 복수 보컬이 겹쳐 단일 음색으로 보기 어렵다는 표시.
- **이펙트 플래그**: EQ, 압축, 왜곡, 리버브 등 후처리 영향이 크다는 표시.
- **유효 음성 길이**: 품질 기준을 통과한 보컬 구간의 총 길이.
- **유효 세그먼트**: 유성 비율, SNR, 클리핑, 잔향, 분리 품질 등의 기준을 통과한 분석 구간.
- **VAD**: 음성이 존재하는 구간과 비음성 구간을 판정하는 과정.
- **F0 confidence**: 특정 프레임의 F0 추정을 신뢰할 수 있는 정도.
- **두 경로 F0 합의**: 서로 다른 F0 모델 또는 입력 경로의 추정값이 센트 기준 안에서 일치하는 정도.
- **옥타브 불일치율**: F0 경로 사이에 두 배 또는 절반 차이가 나는 프레임의 비율.
- **마이크 조건 일관성**: 녹음 거리, 각도, 기기, 게인이 목표 프로토콜과 얼마나 일치하는지 나타내는 상태.
- **도메인 갭**: 스마트폰 생목과 스튜디오 보컬처럼 입력 환경 차이로 특징 분포가 달라지는 현상.
- **품질 게이트**: 분석에 사용할 수 있는 입력만 통과시키는 규칙.
- **품질 점수**: 잡음, 잔향, 클리핑, 유효 길이 등 관측 품질을 요약한 값. 사용자 가창 능력 점수가 아니다.
- **신뢰도 confidence**: 현재 분석 결과의 안정성과 근거 충분성을 나타내는 값. 보정 전 모델 점수를 실제 확률로 표현하지 않는다.
- **보정 calibration**: 모델 점수와 실제 오류율 또는 사람 평가 사이의 관계를 맞추는 과정.
- **미측정**: 해당 항목을 계산할 데이터가 없음.
- **분석 불가**: 데이터는 있으나 품질 또는 모델 조건 때문에 신뢰할 결과를 만들 수 없음.
- **낮은 결과**: 정상적으로 측정했으며 실제 지표가 기준보다 낮음.
- **재측정 필요**: 미측정 또는 분석 불가를 해결하기 위해 추가 녹음이 필요한 상태.
- **폴백 fallback**: 신뢰도가 낮을 때 임의 점수를 내지 않고 음역 중심 결과, 제한된 설명 또는 재측정 안내로 전환하는 처리.
- **모델 매니페스트**: 모델 ID, 버전, 체크포인트, 파라미터, 라이선스와 피처 스키마를 기록한 정보.

# 10. 프로젝트 핵심 데이터·추천 용어

- **사용자 보이스 프로필**: 사용자의 편안·실사용 음역, 음높이별 안정도, 조건별 음색 피처·임베딩·프로토타입, 성구, 분석 품질과 신뢰도.
- **곡 보컬 요구 프로필**: 곡의 구간별 음역·테시투라·지속 고음, 원곡 보컬의 음색 프로토타입, 발성 표현, 랩·듀엣·이펙트 플래그.
- **곡 분위기 프로필**: 곡 전체, 반주, 가사와 사람 검수로 구성한 분위기·상황·구간별 특성.
- **구간 프로필**: 곡 또는 사용자 녹음을 verse, chorus, peak와 음높이·성구 조건으로 나눠 만든 분석 단위.
- **추천 후보 게이트**: 권리, 데이터, 품질과 분석 조건을 통과한 곡만 추천 후보로 사용하는 규칙.
- **음역 적합도**: 후보 키에서 곡의 주요 음역이 사용자 편안·실사용 음역에 들어오는 정도.
- **음색 관계 점수**: 조건별 사용자 음색과 곡 보컬 특성 사이의 가까움·조화·대비 관계.
- **표현 적합도**: 사용자의 관측 가창 표현과 곡이 요구하는 표현 특성의 관계.
- **종합 적합도**: 음역, 음색 관계, 표현, 곡 분위기, 품질과 신뢰도를 결합한 추천 지표.
- **추천 근거**: 추천 결과에 실제로 사용된 측정값, 비교 구간, 선택 키와 신뢰도.
- **부담 구간**: 음역, 지속 고음, 성구 전환 또는 긴 호흡 등으로 사용자가 어려움을 겪을 가능성이 높은 곡 구간.
- **키 시뮬레이션**: 후보 키마다 곡 음역을 이동시켜 사용자 음역, 예상 성구와 해당 음높이에서의 음색 궤적을 비교하는 과정.
- **평가 불가**: 근거가 부족해 적합도나 추천 설명을 생성하지 않는 상태.

# 11. 금지하거나 구체화할 표현

- **톤** → 음색, 피치, 분위기 또는 녹음 EQ 중 무엇인지 명시한다.
- **볼륨** → 녹음 레벨, 라우드니스, 음압 또는 재생 볼륨으로 명시한다.
- **성량 점수** → 보정된 SPL 측정이 아니면 사용하지 않는다. 녹음 RMS, 발성 강도 또는 다이내믹스로 표현한다.
- **음정** → 피치 정확도 또는 음정 간격으로 명시한다.
- **키** → 곡 원키, 키 시프트 또는 추천 키로 명시한다.
- **가성/진성 판정** → 가성 우세/진성 우세와 신뢰도로 표현한다.
- **음색 점수 하나** → 음색 피처, 임베딩, 조건별 프로토타입과 신뢰도로 분해한다.
- **가수와 비슷하므로 잘 부른다** → 음색 유사도와 곡 적합도를 분리한다.
- **밝은 음색이므로 밝은 노래를 좋아한다** → 음색과 취향·감정을 분리한다.
- **녹음 파형이 크므로 성량이 좋다** → 녹음 레벨과 실제 성량을 분리한다.
- **데이터가 없으므로 0점** → 미측정, 분석 불가 또는 재측정 필요로 표시한다.

# 12. 팀 합의가 필요한 후속 항목

- 사용자 음역을 절대 음높이와 개인 음역 내 상대 위치 중 어떤 축으로 시각화할지
- 저·중·고음 구간을 절대 음높이로 나눌지 개인별 음역 비율로 나눌지
- 진성·가성·믹스 판정에 사용할 라벨과 최소 신뢰도
- 음색 피처의 최초 채택 목록과 단위·정규화 방식
- 음색 임베딩 모델과 스마트폰↔스튜디오 도메인 갭 검증 방법
- 사용자별 음색 궤적을 만들기 위한 필수 녹음 음높이·모음·발성 강도
- 음색 유사도와 음색 적합도를 분리하는 추천 공식
- SNR, 유효 음성 길이, 클리핑, 잔향 등 품질 게이트의 초기 기준
- dBFS와 dB SPL 중 제품이 실제로 측정·표시할 범위
- 용어별 사용자 화면 문구와 내부 데이터 필드명
